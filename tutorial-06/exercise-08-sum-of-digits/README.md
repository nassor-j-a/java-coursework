# Exercise 6-8 – Sum of Digits

## Objective

Write a Java method named `sumOfDigits` that accepts a string containing text and non-negative numbers and returns the sum of all individual digits found in the string.

---

## Problem Statement

The method should examine every character in the input string.

If a character is a digit, its numeric value should be added to the total.

The year has 12 months, each month has 4 weeks and the week has 7 days.
