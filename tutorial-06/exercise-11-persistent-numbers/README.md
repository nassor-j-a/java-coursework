# Exercise 6-11 – Persistent Numbers

## Objective

Write Java methods that calculate the multiplication of the digits of a number and determine the persistence of that number.

The persistence of a number is the number of multiplication steps required to reduce the number to a single digit by repeatedly multiplying its digits.

---

Write a method named `multiplyDigits` that takes an integer and returns the product of all its digits.
