# Exercise 9-1 – Point

## Objective

Implement a Java class named `Point` to represent a point in the Cartesian plane using X and Y coordinates.

The exercise demonstrates constructors, instance methods, static methods, object manipulation, method overloading, and class variables.

---

## Problem Statement

A point in the Cartesian plane is represented by its X and Y coordinates.

The `Point` class should provide methods for:

- Adding two points
- Adding another point to the current point
- Swapping two points
- Swapping the current point with another point
- Displaying a point using `toString()`
- Tracking the number of Point objects created
