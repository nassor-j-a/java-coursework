# Exercise 9-2 – Triangle

## Objective

Implement a Java class named `Triangle` using the `Point` class from Exercise 9-1.

A Triangle is represented by three Point objects that correspond to its three vertices.

---

## Problem Statement

A triangle can be described using three points representing its vertices.

The `Triangle` class should provide:

- A default constructor
- A parameterized constructor
- A `copy()` method
- A `rotate()` method
- A `toString()` method
- A class variable that counts Triangle objects
- A `main` method for testing
