# Exercise 8-5 – Clerk

## Objective

Write a Java program that defines a `Clerk` class and calculates the monthly salary of a clerk based on:

- Year of birth
- Salary class
- Marital status

The exercise also demonstrates static methods, instance methods, constructors, and modifying object state.

---
