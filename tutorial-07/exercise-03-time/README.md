# Exercise 8-3 – Time

## Objective

Write a Java class named `Time` that represents a time using hours, minutes, and seconds.

The exercise demonstrates classes, constructors, methods, and handling changes between seconds, minutes, and hours.

---

## Problem Statement

Define a `Time` class with the following attributes:

- `hours` – int
- `minutes` – int
- `seconds` – int

The class should provide:

- A default constructor.
- A constructor that accepts hours, minutes, and seconds.
- A method to return the hours.
- A method to return the minutes.
- A method to return the seconds.
- A method to add one minute.
- A method to add one second.
- A method to add one hour.

---

## Algorithm

### Default Constructor

Set all time values to zero:

```text
hours = 0
minutes = 0
seconds = 0
