# Exercise 7-22 — Look And Say

## Description

The look-and-say sequence is a sequence of integers where each term describes the digits of the previous term.

The sequence begins:

```text
1
11
21
1211
111221
312211
13112221
1113213211
...
```

Each term is generated by reading the previous term from left to right and counting groups of consecutive identical digits.

Examples:

```text
1      → 11
11     → 21
21     → 1211
1211   → 111221
111221 → 312211
```

For example, `111221` is read as:

```text
three 1s → 31
two 2s   → 22
one 1    → 11
```

Therefore:

```text
111221 → 312211
```

The exercise requires a recursive method `lookAndSay` that prints the first `n` terms of the sequence.

## Methods

### `lookAndSay(int n, String term)`

Recursively prints the current term and then generates the next term.

```java
public static void lookAndSay(int n, String term)
```

The method stops when `n` becomes `0`.

### `nextTerm(String term)`

Generates the next term of the sequence recursively.

```java
public static String nextTerm(String term)
```

For example:

```text
nextTerm("1")      → "11"
nextTerm("11")     → "21"
nextTerm("21")     → "1211"
nextTerm("1211")   → "111221"
```

### `countSameDigits(String term, char digit, int index)`

Counts how many consecutive occurrences of a digit appear starting from a particular position.

For example:

```text
term = "111221"
digit = '1'
```

The method returns:

```text
3
```

because there are three consecutive `1`s at the beginning.

## Recursive Logic

The main recursive method follows this pattern:

```text
Print current term
        ↓
Generate next term
        ↓
Call lookAndSay with n - 1
        ↓
Repeat
```

For example:

```text
lookAndSay(4, "1")
        ↓
print 1
        ↓
lookAndSay(3, "11")
        ↓
print 11
        ↓
lookAndSay(2, "21")
        ↓
print 21
        ↓
lookAndSay(1, "1211")
        ↓
print 1211
        ↓
lookAndSay(0, "111221")
        ↓
stop
```

## Base Cases

### `lookAndSay`

```java
if (n == 0) {
    return;
}
```

When there are no more terms to print, recursion stops.

### `nextTerm`

```java
if (term.length() == 0) {
    return "";
}
```

When there are no digits left to process, the method stops.

### `countSameDigits`

```java
if (index == term.length()) {
    return 0;
}
```

When the end of the term is reached, there are no more matching digits to count.

---

## Important Point

The sequence is based on **groups of consecutive identical digits**, not simply counting all occurrences of a digit.

For example:

```text
1211
```

must be read as:

```text
one 1
one 2
two 1s
```

Therefore:

```text
1211 → 111221
```

It is **not**:

```text
three 1s and one 2
```

because the `1`s are separated into different groups.

---

## Complexity

The size of each term grows as the sequence progresses, so generating later terms requires more work.

For a term of length `k`:

- `countSameDigits()` can examine several digits.
- `nextTerm()` recursively processes all groups.
- `lookAndSay()` recursively generates the requested number of terms.

The exact running time therefore depends on the length of the generated terms.

The recursion depth of `lookAndSay()` is `n`, while the helper recursion also depends on the length of the current term.
