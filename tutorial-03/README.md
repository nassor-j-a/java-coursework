# Tutorial 3 – Decision Structures

## Overview

This tutorial introduces decision-making in Java using:

- if
- if-else
- nested if
- switch
- conditional operator (`?:`)

The exercises focus on solving practical problems involving mathematical calculations, validation, classification, and user interaction.
